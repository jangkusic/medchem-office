[도구 1 · 구조 그리기 · 물성]
  - 분자량, 정확 질량, cLogP, TPSA, HBD/HBA, 회전결합
  - pKa 와 cLogD(pH 7.4) 예상값 (작용기 기준값 + 주변 전자 효과, 평균 0.4 정도 오차)
  - Lipinski, Veber, CNS MPO
  - 입체화학 — 비칭 탄소와 E/Z 이중결합 자리를 찾아 R/S·E/Z 를 표시
    "모든 이성질체 보기" 를 누르면 가능한 입체이성질체를 전부 그려서 보여줍니다.
    지금 그린 것이 어느 것인지 표시되고, 다른 것을 골라 편집기로 보낼 수 있어요.
  - 3D 보기 — 편집기 툴바의 3D 단추를 누르면 열립니다.
            고른 구조 하나만, 실제 3D 좌표를 계산해서 보여줘요. SDF 로 저장 가능
  - 화합물 목록 저장 (타깃별 활성값), CSV 내보내기
  - SMILES / MOL / CDXML 불러오기, ChemDraw(.cdxml) 저장

  이 도구는 구조 그리기와 물성만 다룹니다.
  저장한 화합물 목록을 표로 보고 SAR 을 보는 화면은 도구 4 로 갑니다.
  저장은 지금도 되고, 백업은 저장 칸 아래 "CSV 내보내기" 로 하세요.

[단축키]
  ChemDraw 와 같은 방식입니다.

  마우스를 원자 위에 두고 글자를 누르면 → 그 원자가 바로 바뀝니다 (도구는 그대로)
    C N O S P F I / L = 염소(Cl) / B = 브로민(Br)
  마우스를 결합 위에 두고 숫자를 누르면 → 결합이 바뀝니다
    1 단일, 2 이중, 3 삼중   (결합 위에서 글자는 아무 일도 안 해요)
  빈 곳에서 누르면 → 그 도구로 바뀝니다
    X 단일 결합, W 쐐기, H 점선 쐐기, Y 물결, T 글상자, J 벤젠, E 반응 화살표
  스페이스바 → 방금까지 그리던 구조 하나를 통째로 선택
    (선택 도구로 바뀌어서 바로 끌어 옮기거나 Delete 로 지울 수 있어요)

  모두 Ctrl+Z 로 되돌릴 수 있습니다.
  오른쪽 위 "단축키 설정" 에서 바꿀 수 있고, "ChemDraw 기본값으로" 로 되돌아갑니다.

[3D 보기에 대해]
  결합 길이·결합각·평면성·원자끼리 밀어내기만 넣은 가벼운 계산이에요.
  방향족 고리는 평평하게, 사이클로헥산은 의자형으로 나옵니다.
  보기용으로는 충분하지만 도킹에 바로 넣을 품질은 아니니,
  도킹할 때는 전용 프로그램에서 좌표를 다시 만드세요.

[화합물 목록은 함께 씁니다]

  백업하려면 화합물 목록 탭에서 CSV 로 내보내세요.
  브라우저 데이터를 지우면 목록도 함께 지워집니다.
